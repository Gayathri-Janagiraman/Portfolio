QueueFlow

Real-Time Hospital Queue Management System
GitHub Live Demo

QueueFlow is a full-stack MERN application that replaces physical hospital waiting lines with a real-time digital queue. Patients can book a token, track their live queue position, and see who is currently being served without refreshing the page. Admins can manage the complete queue lifecycle from a centralized dashboard.

// key features
  • Digital token booking
  • Real-time queue updates
  • Live queue position tracking
  • Estimated waiting time
  • JWT authentication
  • Role-based User / Admin access
  • Admin dashboard — call, skip, recall, cancel, complete tokens
  • Multi-department queue management
// tech stack
--react --javascript --tailwind --node --express --mongodb --jwt --socket.io
